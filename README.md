# Бот для управления задачами прорабов

Telegram-бот на **Python 3.10+ / aiogram 3 / SQLite**.
Шеф ставит задачи прорабам, бот доставляет их и считает статистику.
Решение «выполнено или нет» всегда принимает шеф.

## Быстрый старт

```bash
python -m venv .venv && source .venv/bin/activate      # Windows: .venv\Scripts\activate
pip install -r requirements.txt
cp .env.example .env                                   # заполните BOT_TOKEN и ADMIN_IDS
python -m bot.main
```

1. Создайте бота у [@BotFather](https://t.me/BotFather), токен — в `BOT_TOKEN`.
2. Свой Telegram ID узнайте у [@userinfobot](https://t.me/userinfobot), впишите в `ADMIN_IDS`
   (можно несколько шефов через запятую — у каждого будут свои прорабы).
3. Запустите бота, откройте его, нажмите `/start` — вы шеф.
4. В меню «👷 Прорабы» скопируйте **ссылку-приглашение** и отправьте прорабам.
5. Прораб переходит по ссылке → шеф подтверждает заявку кнопкой → можно ставить задачи.

Проверка логики без Telegram: `python -m tests.smoke_test`

## Как это работает

### Отправка задачи (шеф)

1. «➕ Новая задача».
2. Отправьте боту задачу — **текстом, фото или голосовым** (одной и той же кнопки/окна для всех; к фото можно добавить подпись).
3. Выберите **важность**: 🟢 обычная / 🟡 важная / 🔴 срочная. Сроков и дедлайнов нет.
4. Выберите прорабов (одного или нескольких) и нажмите «📤 Отправить выбранным» — или сразу «👥 Отправить всем».

Каждому прорабу создаётся своя задача, чтобы по ним считалась отдельная статистика.
Сообщение приходит прорабу в том же виде (фото остаётся фото, голосовое — голосовым) с заголовком «Новая задача · важность».
Дополнительно принимаются видео и файлы. Если отправить альбом из нескольких фото, берётся первое.

### Панель прораба

* Задачи копятся у прораба: «📋 Мои задачи» — список задач в работе (срочные сверху), нажатие открывает задачу.
* «📈 Моя статистика» — сколько задач получено, выполнено, не выполнено и в работе, процент выполнения,
  среднее время и последние задачи.
* Прорабу ничего подтверждать не нужно — он только получает задачи.

### Отметка результата (шеф)

«📋 Активные задачи» → нажать на задачу → **✅ Выполнено / ❌ Не выполнено** (или 🚫 Отменить, если отправили по ошибке).
Статистика прораба обновляется сразу.

Статусы: `🔧 В работе` → `✅ Выполнена` / `❌ Не выполнена` / `🚫 Отменена`.

### Роли

* **Шеф** — из `ADMIN_IDS` (можно несколько, у каждого свои прорабы). Видит и меняет только свои задачи.
* **Прораб** — регистрируется по ссылке-приглашению шефа и после его подтверждения. Видит только свои задачи.

### Статистика (шеф: 📊, прораб: 📈)

| Показатель | Как считается |
|---|---|
| Всего / ✅ / ❌ / 🔧 | количество задач по статусам |
| Выполнение | выполнено ÷ (выполнено + не выполнено) |
| Среднее время | от отправки до отметки «выполнено» |

У шефа: период 7 / 30 дней / всё время, сводка по каждому прорабу и итог по участку,
карточка прораба (разбивка по важности, последние 10 задач), экспорт CSV для Excel.

### Автоматика

Одна: утром в `DIGEST_HOUR` шеф получает сводку — сколько задач сейчас в работе у каждого прораба
(если задач нет — сводка не приходит). Не нужна — уберите `_digest` в `bot/scheduler.py`.

### Обновление со старой версии

Если вы уже запускали прошлую версию, ничего удалять не нужно: при первом запуске старые задачи
(с названием и сроком) переносятся в таблицу `tasks_legacy` и в статистику не попадают.
Прорабы и шефы сохраняются.

## Структура проекта

```
bot/
  main.py        запуск, сборка диспетчера
  config.py      настройки из .env
  db.py          SQLite: таблицы, запросы, статистика
  scheduler.py   утренняя сводка шефу
  texts.py       заголовки задач и блоки статистики
  keyboards.py   все кнопки
  states.py      шаги диалога (содержимое → важность → прорабы)
  filters.py     проверка роли (шеф / активный прораб)
  notify.py      безопасная отправка (текст, фото, голосовое) и редактирование
  utils.py       время (UTC в базе, локальное в интерфейсе)
  handlers/      common (/start, /help), chief, foreman, fallback
tests/smoke_test.py
```

Таблицы: `users` (шефы и прорабы), `tasks` (вид, file_id, текст, важность, статус, время отправки и закрытия), `meta` (служебное).
Все даты хранятся в UTC, показываются в часовом поясе `TZ` (по умолчанию `Asia/Dushanbe`).

## Запуск на сервере

Простой вариант — systemd (`/etc/systemd/system/foreman-bot.service`):

```ini
[Service]
WorkingDirectory=/opt/foreman-bot
ExecStart=/opt/foreman-bot/.venv/bin/python -m bot.main
Restart=always
User=bot

[Install]
WantedBy=multi-user.target
```

Резервная копия — просто копия файла `data/bot.db`.

## Ограничения и что можно добавить дальше

* Диалоги (создание задачи) хранятся в памяти: при перезапуске бота незавершённое создание сбрасывается.
  Сами задачи в базе не теряются. Для продакшена с частыми перезапусками подключите `RedisStorage`.
* Идеи для развития: ответ прораба фото-отчётом, повторяющиеся задачи, шаблоны задач, группы прорабов.
